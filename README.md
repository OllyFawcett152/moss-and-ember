# Moss & Ember

A soft, warm light theme for VS Code: parchment backgrounds, olive greens and burnt oranges, with no cold blues.

## Palette

| Role | Colour |
| --- | --- |
| Editor background | `#fbf2e2` parchment |
| Activity & status bar | `#8a9a5b` olive |
| Accents | `#c4622d` burnt orange |
| Keywords | `#b8492a` rust |
| Functions | `#c27420` amber |
| Classes & types | `#9c3d2a` brick |
| Strings | `#6f7f2a` olive |
| Numbers | `#8e4a6b` plum |
| Comments | `#a8916f` muted brown, italic |

## Install

1. Open the Extensions view and search for **Moss & Ember**.
2. Run **Preferences: Color Theme** and choose **Moss & Ember**.

## Suggested icons

Pairs well with [Material Icon Theme](https://marketplace.visualstudio.com/items?itemName=PKief.material-icon-theme) and these settings:

```json
"workbench.iconTheme": "material-icon-theme",
"material-icon-theme.saturation": 0.85,
"material-icon-theme.folders.color": "#e08a3c",
"material-icon-theme.rootFolders.color": "#9aae5c"
```
